## 6. Defects found & fixed during coordinator verification

1. **Corrupt root `package-lock.json`** — contained `backend/node_modules/@esbuild/*` entries with empty versions, breaking every root `npm install` with `Invalid Version:`. Fixed by deleting and regenerating the lock (406 entries, zero bad). Rebuilt ZIP carries the clean lock (sha256 in §8).
2. **`netlify.toml` build command ran Prisma from the wrong directory** — `npx --prefix backend prisma generate` executes with cwd at the repo root, so Prisma could not find `schema.prisma` and the whole Netlify build would have failed at the generate step. Fixed to `cd backend && npx prisma generate && npx prisma migrate deploy && npm run seed && cd ../admin-website && ...`. Verified by running the verbatim command in the fresh extract (exit 0).
3. **Stale README lines** — root `README.md` still said the backend "cannot run yet" and the admin `/api` proxy was "still to be added". Both were untrue by verification time; corrected.
